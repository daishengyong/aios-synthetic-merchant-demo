# AIOS synthetic merchant orders

This repository contains a public, no-login merchant-style order list for
testing an AI agent's browser collection and downstream processing. Every
order, amount, status, and date is fictional. The site is not affiliated with
JD, Webkio, or any real merchant.

The published pages are in `docs/`. The intended URL is
https://daishengyong.github.io/aios-synthetic-merchant-demo/ .

Automated reading and extraction of these synthetic rows for the AIOS Dot
exercise is permitted by the repository owner. See [DATA_USE.md](DATA_USE.md).

The private `weiliang-dot-relay` repository receives Dot's run envelopes and
ECS status receipts; no run data belongs in this public demo repository.
